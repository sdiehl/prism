docs/internal/CONTRIBUTING.mddocs/internal/CONTRIBUTING.md# Contributing to Prism

External contributions are welcome. Including ones that use coding assistants and AI models.

A checklist for contributing upstream to the Prism repo.

- [ ] Write a brief human readable description of the change and which subsystem it impacts in the PR body.
- [ ] Include any design notes or a summary of the agentic reasoning chain or summary plan that produced the output in the PR body including core features and goals of the contribution.
- [ ] Do not include any AI agent riders on commit messages, the contributions should be from the human's Github account only.
