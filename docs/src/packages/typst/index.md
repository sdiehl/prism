# typst

API documentation generated from the project's source by `prism docs`. Function and value signatures are the typechecker's inferred types; prose comes from `-- |` doc comments.

## Modules

- [Typst.Markup](./typst-markup.md) - Typst's markup layer as typed combinators: headings, emphasis, lists, figures, tables, links, labels and references.
- [Typst.Value](./typst-value.md) - Typst's value vocabulary as Prism types.
- [Typst](./typst.md) - Typed, deterministic construction of Typst source documents.
